Materi Perangkat Lunak (Software)

Bagian 1

Apa itu Perangkat Lunak (Software)?

Perangkat Lunak (Software) adalah kumpulan instruksi, data, atau program yang digunakan untuk mengoperasikan komputer dan menjalankan tugas tertentu.

Berbeda dengan Hardware (perangkat keras) yang bisa dipegang dan dilihat fisiknya seperti mouse atau keyboard, Software bersifat tidak berwujud fisik tetapi dapat dirasakan manfaatnya melalui layar monitor.

💡 Analogi Mudah: Jika komputer adalah tubuh manusia (Hardware), maka Software adalah jiwa atau pikiran yang membuat tubuh tersebut bisa bergerak dan berpikir!

Fungsi Utama Software

  • Mengatur dan mengendalikan perangkat keras.
  • Menjadi penghubung antara pengguna (Brainware) dan Hardware.
  • Memproses perintah data input menjadi informasi output.
Bagian 2

Sistem Operasi (Operating System / OS)

Sistem Operasi (OS) adalah software paling utama dan penting yang bertugas mengelola seluruh sumber daya komputer serta menjembatani komunikasi antara pengguna dengan aplikasi lain. Tanpa OS, komputer tidak akan bisa dinyalakan!

Contoh-Contoh Sistem Operasi Populer:

Windows

Dibuat oleh Microsoft. Sangat populer digunakan pada PC dan laptop sekolah atau kantor.

Linux

Sistem operasi *Open Source* (gratis dan bebas dimodifikasi). Sangat aman dari virus.

macOS

Sistem operasi buatan Apple khusus untuk komputer Mac dan Macbook.

Android

Sistem operasi berbasis Linux khusus untuk perangkat smartphone dan tablet.

Bagian 3

Perangkat Lunak Aplikasi (Application Software)

Software Aplikasi adalah program yang dirancang khusus untuk membantu pengguna menyelesaikan tugas-tugas tertentu, seperti mengetik dokumen, menghitung data, atau menjelajahi internet.

1. Pengolah Kata (Word Processor)

Digunakan untuk membuat surat, laporan, dan dokumen teks.

Contoh: MS Word, Google Docs, LibreOffice Writer
2. Pengolah Angka (Spreadsheet)

Digunakan untuk mengolah data tabel, angka, serta grafik perhitungan.

Contoh: MS Excel, Google Sheets
3. Pembuat Presentasi

Digunakan untuk merancang slide presentasi yang menarik visualnya.

Contoh: MS PowerPoint, Canva, Google Slides
4. Peramban Web (Web Browser)

Digunakan untuk mengakses dan berselancar di dunia internet.

Contoh: Google Chrome, Mozilla Firefox, Edge
Bagian 4

Perangkat Lunak Perkakas (Utility Software)

Utility Software adalah program pendukung yang berfungsi untuk merawat, mengoptimalkan, dan mengamankan sistem komputer agar tetap berjalan lancar dan aman dari gangguan.

Antivirus

Melindungi komputer dari serangan virus, malware, dan spyware berbahaya.

Contoh: Avast, Windows Defender, Smadav

File Archiver / Kompresi

Mengecilkan ukuran file agar mudah dikirim melalui internet.

Contoh: WinRAR, 7-Zip

Pembersih Disk (Cleaner)

Membersihkan sampah sistem (junk files) agar memori komputer lega kembali.

Contoh: CCleaner
